About FreePDFTools

FreePDFTools is a small collection of PDF utilities — merge, split, resize, rotate, and convert — built to solve one problem: getting a quick PDF task done without installing software, creating an account, or sending your document to someone else's server.

How it works

Every tool on this site runs entirely inside your web browser using JavaScript. When you "upload" a file, it is loaded directly into your browser's memory and processed there — it is never sent to a server or stored anywhere. Once you close the tab, nothing remains.

Why it's free

This site is supported by a small number of ads, which covers the cost of running it. There are no accounts, subscriptions, or hidden fees for the core tools.
