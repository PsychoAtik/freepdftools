How to merge PDF files

  1. Click the box above and choose the PDF files you want to combine (or drag them in).
  2. Use the up/down arrows next to each file to put them in the order you want the final document to read.
  3. Press "Merge PDFs" — your browser will build the combined file and download it automatically.
